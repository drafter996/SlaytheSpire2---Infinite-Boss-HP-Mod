# InfiniteBossHP

专为胡局设计的《杀戮尖塔 2》第三幕最终 Boss 无限血量 Mod。

击败第三幕的最终 Boss 后，战斗将进入影子阶段。影子会继续与你交手，累计伤害图标会记录你对它造成的伤害，让你看看卡组输出的上限究竟在哪里。

影子以玩家的鲜血维系：当最后一名存活玩家即将受到致命伤害时，影子随之消散，战斗以胜利结束。10 难度连续挑战两名 Boss 时，影子阶段只会出现在第二名 Boss 身上。

## 安装要求

- 《杀戮尖塔 2》
- BaseLib

## 安装方法

可以从 Steam 创意工坊订阅，或从 Nexus Mods 下载发布包。手动安装时，将压缩包中的 `InfiniteBossHP` 文件夹解压到游戏的 `mods` 目录，并单独安装 BaseLib。
